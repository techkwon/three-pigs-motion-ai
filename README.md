# 아기 돼지 모션 대결 — AI 모델 비교 실험

「아기 돼지 삼형제」를 현대적으로 다시 쓴 모션그래픽(HTML 한 파일, 인라인 SVG + CSS/JS)을 AI 모델에게 같은 지시문으로 만들게 하고, 이름을 가린 채 세 회사의 모델이 채점한 기록입니다. 2026년 10월 19일, 중학교 수업 자료 준비 중에 한 실험입니다.

**보고 페이지:** https://techkwon.github.io/three-pigs-motion-ai/ — 다섯 작품의 실제 재생 클립, 스크롤에 따라 「점수로 지은 집」이 쌓이고 순위가 바뀌는 결과 그림, 같은 초 장면 비교, 채점관별 점수, 자주 묻는 질문

기계가 읽는 자료: [`data/results.json`](data/results.json) · [`data/results.csv`](data/results.csv) · [`index.md`](index.md)(보고서 마크다운판) · [`llms.txt`](llms.txt)

## 무엇을 비교했나

| 라운드 | 질문 | 작품 |
|---|---|---|
| 1라운드 | 두 모델이 혼자 만들면 누가 나은가 | Claude Opus 5.5 단독, GPT 6.1 sol 단독 |
| 2라운드 | 두 모델이 일을 나누면 더 나은가 | 협업(GPT 설계 → Opus 구현 → GPT 검토 → Opus 수정) |
| 3라운드 | 협업이 이긴 까닭이 협업 자체인가, 더 많은 시간·정보·반복인가 | 솔로플러스: 단독 모델에게 협업과 같은 참고 자료, 자기 설계, 스크린숏을 보고 하는 자기 검토와 수정 1회를 준 작품 두 편 |

## 3라운드 결과 (다섯 작품, 블라인드 평균 100점 만점)

| 순위 | 작품 | 평균 | 제작 시간 |
|---|---|---|---|
| 1 | Opus 5.5 솔로플러스 「문 열어, 나야」 | 92.7 | 약 67분 |
| 2 | 협업 「늑대가 된 여름」 협업판 | 90.7 | 약 108분 |
| 3 | GPT 6.1 sol 솔로플러스 「마감 늑대와 빈칸 있는 집」 | 79.0 | 약 38분 |
| 4 | Opus 5.5 단독 「아기 돼지 삼형제 2050」 | 72.7 | 약 34분 |
| 5 | GPT 6.1 sol 단독 「늑대가 된 여름」 | 70.0 | 약 10분 |

채점관: Claude Sonnet 5.5(Anthropic), GPT 6.1 sol(OpenAI, 코덱스 CLI), Gemini 4 Argon high(Google, agy). 다섯 항목(스토리 구성, 이야기 흐름, 화면 구성, 모션 품질, 기술 완성도) × 20점입니다.

이 결과는 협업의 승리에 시간·정보·검토와 수정 기회가 크게 작용했을 가능성을 보여 줍니다. 같은 이점을 받은 Opus는 혼자서도 협업 수준에 이르렀습니다(2점 차이가 의미 있는 차이인지는 확인하지 않았습니다). GPT는 같은 이점을 받고도 협업작보다 약 12점 낮았습니다. 모든 작품을 한 번씩만 만들었고, 점수는 같은 라운드 안에서만 비교해야 합니다. 자세한 내용과 주의할 점은 보고 페이지에 있습니다.

## 알려진 문제

- `gpt-6.1-sol-plus/index.html`: 수정 단계에서 생긴 버그로, 0~45초 동안 첫째 돼지의 팔이 화면 끝까지 늘어나 주황 띠처럼 보입니다. 실험 기록이므로 고치지 않았습니다.
- `opus-5.5/index.html`: 프레임 사이 경과 시간을 한 번에 최대 0.1초까지만 더하므로, 초당 10프레임보다 느린 기기에서는 슬로모션으로 재생됩니다.

작품과 문서는 AI 모델이 만들었고, 실험 진행과 기록은 Claude Code가 했습니다.
