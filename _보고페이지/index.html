협업은 단독 두 편과 1라운드 채점 결과(강점·약점)를 읽고 시작했고, 검토와 수정을 한 번 더 거쳤습니다. 단독은 같은 지시문만 받고 한 번에 끝냈습니다.

점수는 상대적

같은 채점관도 비교 대상이 바뀌자 단독작 점수가 내려갔습니다(GPT 80.3 → 74.3, Opus 84.3 → 73.0). 1라운드에서는 Opus가 앞섰는데, 협업작 옆에서는 GPT가 근소하게 앞섰습니다. 점수는 같은 라운드 안의 차이로 읽어야 합니다.

한 번씩만

모든 작품을 한 번씩만 만들었습니다. 협업작은 제목이 GPT 단독작과 같아서, 채점관이 두 작품의 관계를 짐작했을 수 있습니다.

단독 작품의 강점과 약점

GPT 6.1 sol · 잘 짜인 그림책 편집

화면 디자인, 이야기의 매듭, 재생기의 튼튼함이 강점입니다. 움직임은 장식에 머뭅니다.

강점

  • 편집 디자인 수준의 화면. 큰 한글 헤드라인(「일단, 빨리 살고 싶어.」)과 정보 카드(「설치 60분」, 스마트홈 앱의 「24°」, 셋째의 작업 목록)로 한눈에 읽힙니다.
  • 세 형제 모두에게 역할을 돌려준 결말. 빠른 손은 그늘막, 센서는 열 확인, 연락망은 이웃 부르기를 맡습니다.
  • 튼튼한 재생기. 실제 시계 기준이라 느린 기기에서도 84초가 정확하고, 일시정지·탐색 막대가 있습니다.

약점

  • 슬라이드쇼에 가까운 움직임. 대부분 흔들림·둥실 같은 반복 동작과 장면 페이드입니다.
  • 위기와 해결을 자막으로 설명. 정전과 쉼터가 되는 과정이 자막 몇 줄로 지나갑니다.
  • 작은 배치 흠. 7장면 설명 글이 자막 상자에 가리고, 휴대폰 표지에서 안내 문구가 겹칩니다.

Claude Opus 5.5 · 움직이는 사건과 숫자

움직임이 이야기를 끌고 갑니다. 대신 재생 시간 계산이 기기 성능에 흔들립니다.

강점

  • 의미 있는 모션. 카메라가 한 거리를 옮겨 다니고, 집이 떨어져 튕기고, 에어컨이 튀어나오고, 정전에 섬광이 터집니다.
  • 숫자로 보여 주는 인과. 실내 41°C → 39°C → 27°C, 전력 57% → 88% → 「정전!」.
  • 원작 뼈대를 살린 전개. 단계적 피신, 형들의 비웃음 복선, 셋째가 문을 여는 반전.

약점

  • 프레임 기준 시간 계산. 느린 기기에서 슬로모션이 됩니다(시험에서 88초 작품이 118초 걸림).
  • 정보가 몰리는 장면. 말풍선·딱지·두 줄 자막이 한꺼번에 나오고, 휴대폰에서는 자막이 아주 작습니다.
  • 형들의 역할이 피신에 그침. 결말에서 첫째·둘째가 무엇을 보탰는지는 드러나지 않습니다.

시험 방법

  • 과제: 모든 작품이 같은 지시문을 따랐습니다. index.html 한 파일, 인라인 SVG와 CSS/JS 애니메이션, 외부 자원 금지, 약 60~90초, 재생·다시 보기 버튼, 한국어 자막, 16:9 반응형, 콘솔 오류 금지라는 조건입니다.
  • 단독 제작: GPT 6.1 sol은 코덱스 CLI(추론 high)로, Opus 5.5는 하위 에이전트로 각자 빈 폴더에서 만들었습니다.
  • 협업 제작: 설계서 → 구현 → 설계자 검토 → 수정의 4단계였고, 두 모델은 파일(설계서, 검토서)로만 주고받았습니다. 진행자는 일을 넘기고 재생 확인만 했으며, 작품 내용에는 손대지 않았습니다.
  • 재생 확인: 내장 브라우저에서 재생·탐색하며 장면을 찍고, 콘솔 오류(모두 0건), 다시 보기, 휴대폰 화면(375px)을 확인했습니다. 시험 창이 초당 4~5프레임으로 느려서 Opus 단독작은 화면 갱신 신호를 60fps처럼 바꿔 끼워 재생했습니다(작품 코드는 그대로).
  • 3라운드(대조 실험): 단독 모델에게 협업과 같은 이점을 주었습니다. 같은 참고 자료(collab/_ref: 단독 두 편, 과제지시문, 1라운드 평가 요약)를 읽고 ① 자기 설계서 → ② 구현 → ③ 진행자가 찍은 스크린숏을 보고 자기 검토 → ④ 수정의 4단계를 거쳤습니다. 단계마다 새로 불러 파일로만 이어 갔고, 두 모델 모두 단계 지시문이 같았습니다. 브라우저는 쓰지 않게 했습니다. 다섯 작품 모두 헤드리스 크롬(1600×900, 정상 프레임 속도)으로 같은 시각(5초 간격)에 다시 찍어 채점관에게 주었고, 새 이름표(M·P·R·T·V)로 가렸습니다.
  • 채점: 5항목 × 20점. Claude Sonnet 5.5(Anthropic), GPT 6.1 sol(OpenAI, 코덱스), Gemini 4 Argon high(Google, agy)가 이름을 가린 채 채점했고, 점수는 세 채점관의 평균입니다. 1라운드는 단독 둘(A/B), 2라운드는 세 작품(X/Y/Z), 3라운드는 다섯 작품(M·P·R·T·V)을 새로 채점했습니다.
