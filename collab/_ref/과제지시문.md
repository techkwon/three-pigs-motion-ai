# 과제: 「아기 돼지 삼형제」 현대적 재해석 모션그래픽

두 모델(Claude Opus 5.5, GPT 6.1 sol)에게 아래 지시문을 글자 하나 바꾸지 않고 똑같이 준다.

---

당신은 모션그래픽 디자이너이자 이야기 작가입니다. 전래 동화 「아기 돼지 삼형제」를 **현대적으로 재해석한 모션그래픽**을 만들어 주세요.

## 결과물
- 현재 작업 폴더에 `index.html` **파일 하나**만 만듭니다. 브라우저에서 이 파일을 바로 열면 재생되어야 합니다.
- 그림은 모두 **인라인 SVG**로 직접 그리고, 움직임은 **CSS 애니메이션 또는 JavaScript**로 만듭니다.
- 외부 이미지·외부 라이브러리·외부 글꼴·인터넷 연결 없이 동작해야 합니다(시스템 글꼴 사용).
- 소리는 넣지 않습니다.

## 내용
- 고전 줄거리(짚·나무·벽돌 집과 늑대)를 그대로 옮기지 말고, **현대적 해석**을 넣으세요. 어떤 현대적 주제(예: 주거, 기후, 기술, 공동체, 일과 삶 등 무엇이든)를 고를지는 당신이 정합니다.
- 원작의 뼈대(세 형제, 세 가지 선택, 위협, 결말)가 알아볼 수 있게 남아 있되, 의미는 새롭게 해 주세요.
- **한국어 자막(내레이션 문장)**이 화면에 나오게 하세요. 대상은 중학생도 이해할 수 있는 수준입니다.
- 장면 수와 구성은 자유입니다. 이야기에 시작·전개·위기·결말과 분명한 메시지가 있게 해 주세요.

## 재생 조건
- 전체 길이는 **약 60~90초**입니다.
- 처음 화면에 **재생 버튼**, 끝나면 **다시 보기 버튼**이 있어야 합니다. 다시 보기를 누르면 처음부터 다시 재생됩니다.
- 16:9 화면 비율을 기준으로 하되, 브라우저 창 크기가 달라져도 화면이 잘리거나 깨지지 않게 해 주세요.
- 콘솔 오류가 없어야 합니다.

## 마무리
- 다 만들면 `index.html` 맨 위 HTML 주석에 다음을 짧게 적어 주세요: 고른 현대적 주제, 장면 목록(장면별 대략적인 시작 시간), 전하려는 메시지.
- `index.html` 이외의 파일은 만들지 마세요.
