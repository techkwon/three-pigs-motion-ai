# 협업 디자인 브리프 — 늑대가 된 여름

## 1. 작품의 약속

- **제목:** 늑대가 된 여름
- **부제:** 아기 돼지 삼형제, 그다음 이야기
- **현대적 주제:** 폭염 시대의 주거, 기술의 쓰임, 이웃 돌봄.
- **한 줄 메시지:** 좋은 집은 함께 살아남는 곳이다.
- **대상·형식:** 중학생을 위한 한국어 무음 모션그래픽. 재생 시간 **정확히 88초**. 재생 전 표지와 종료 후 대기 시간은 88초에 포함하지 않는다.

첫째의 ‘속도’, 둘째의 ‘기술’, 셋째의 ‘이웃을 생각하는 준비’가 처음에는 서로 다른 집을 만든다. 폭염이 얇은 집을 달구고, 도시의 냉방 수요가 정전을 일으킨다. 첫째는 둘째에게, 두 형은 다시 셋째에게 피한다. 셋째의 집이 버틴 다음에도 이야기를 끝내지 않는다. 문밖의 이웃을 보고 문을 열며, 첫째의 빠른 손과 둘째의 센서까지 합쳐 마당을 넓힌다. 마지막에는 세 집 모두 개선된다. 앞선 선택을 버리는 대신 각자의 능력을 함께 쓰는 반전이다.

참고 원칙: `solo_gpt.html`의 편집 디자인·재능을 살린 결말·재생기와 `solo_opus.html`의 연속 거리·사건 중심 움직임·단계적 피신·수치 인과를 결합한다. `_ref/평가요약.md`의 다섯 평가 항목을 마지막 검수표에 대응시켰다. 점수 우위는 제작 후 평가할 목표이며, 이 문서가 보장하는 사실로 표현하지 않는다.

**이번 산출물은 이 문서 하나다.** 아래의 `index.html` 사양은 다음 구현 담당자에게 주는 지시다. 참고 폴더는 수정하지 않는다.

## 2. 거리·카메라·정보량 규칙

### 좌표 계약

최종 SVG의 화면은 `viewBox="0 0 1600 900"`. 거리 세계는 **4200×900**, x=0…4200이다. 집·나무·등장인물은 같은 세계에 계속 존재한다. 집을 소개할 때마다 새 배경을 만드는 방식은 쓰지 않는다.

| 세계 요소 | 위치·크기, 세계 좌표 |
|---|---|
| 첫째 집 | 중심 x=850, 외곽 x=610…1090, 지붕 y=460, 바닥 y=700 |
| 둘째 집 | 중심 x=2100, 외곽 x=1780…2420, 지붕 y=400, 바닥 y=700 |
| 셋째 집 | 중심 x=3350, 외곽 x=3070…3630, 지붕 y=420, 바닥 y=700 |
| 기존 그늘나무 | 줄기 x=3750, 바닥 y=700, 수관 위 y=400 |
| 셋째 마당 | x=2780…3720. 처음 그늘막 x=3260…3630, 확장 후 x=2780…3690 |
| 인도·도로 | 발 디딤선 y=700, 도로 y=740…830. 같은 경계선이 모든 팬을 연결한다 |
| 배경 도시 | y=370…690. 원경 대비를 전경의 약 35%로 낮춘다 |

카메라 `C(cx, cy, z)`는 세계의 `(cx,cy)`를 화면 `(800,400)`에 놓는다. 변환 순서는 `translate(800 400) scale(z) translate(-cx -cy)`이다. `z`가 클수록 가까워진다. 아래 앵커 사이에서만 움직인다.

| 기호 | 카메라 값 | 목적 |
|---|---|---|
| O | C(2100,490,0.45) | 세 집터/세 집을 함께 보는 거리 전경 |
| A | C(750,525,1.20) | 첫째 집과 첫째를 분리해 보는 근경 |
| B | C(2000,525,1.20) | 둘째 집과 팬·인물을 보는 근경 |
| C | C(3250,525,1.20) | 셋째 집의 벽·그늘·문을 보는 근경 |
| D | C(3150,525,1.00) | 이웃과 확장된 마당까지 보는 중경 |

A/B/C에서 발 디딤선은 화면 y=610, D에서는 y=575다. 가까운 집 지붕도 화면 y≥250에 둔다. 카메라 전환은 아래 장면표의 시간에만 실행한다. 명시된 이동이 끝난 뒤에는 고정한다. 보통 팬·줌은 `smoothstep(p)=3p²−2p³`, 건축물 착지는 짧은 ease-out, 달리기의 수평 이동은 거의 선형이다. 카메라 흔들기와 의미 없는 지속 줌은 쓰지 않는다.

### 고정 화면층과 화면 점유

세계 위에 종이 질감을 얹고, 그 위에 정보 카드·말풍선·HTML 자막을 둔다. 색조 변화는 세계층에만 적용하여 글자 대비를 유지한다.

- **상단 정보 영역:** 화면 x=56…1544, y=32…230. 챕터 제목, 설명 카드, 수치 계기는 **하나의 공통 카드 슬롯을 교대로 사용**한다. 기존 카드를 지우고 새 카드로 바꾼다. 표에서 `/`로 구분한 두 수치는 한 카드의 두 칸이다.
- **행동 영역:** 중요한 물체·얼굴·도구·문·손의 도착점은 화면 x=64…1536, y=240…610 안에 둔다.
- **말풍선:** 최대 하나. 화면 x=80…580, y=250…375 안에 몸통을 두고 꼬리만 말하는 인물 쪽으로 뻗는다. 인물이 오른쪽에 있으면 좌우 반전한 자리 x=1020…1520을 쓴다. 말하는 인물의 얼굴이나 작동 중인 도구를 가리지 않는다. 글자 수에 맞춰 폭을 줄이고, 아래 원문을 한 줄로 표시한다.
- **자막 전용 안전영역:** 화면 **y=640…900 전체**. 글자 상자만이 아니라 이 띠 전체에 인물, 보조 설명, 게이지, 중요한 소품을 넣지 않는다. y=610…640은 30단위 완충 띠다. 도로·바탕 무늬만 아래로 이어질 수 있다.
- 한 순간의 읽을거리는 **말풍선 0~1개 + 정보 카드 0~1그룹 + 자막 한 문장**. 집 표찰, 인물 이름표, 부가 체크리스트, 영어 장식 문구를 별도로 추가하지 않는다. 다른 집이 화면 가장자리에 보이면 라벨 없이 배경으로 남긴다.
- 표지·마지막 메시지는 별도 규칙을 아래에 명시했다. 영화 본편의 자막은 항상 같은 자리에 있다.

### 시간·수치의 의미

- 바깥 기온은 30초에 43°C가 된 뒤 끝까지 유지한다. 녹색으로 변하는 것은 그늘과 공동체의 안전감이다. 동네가 지구의 기온을 떨어뜨리는 결말로 만들지 않는다.
- 첫째 실내 29→41°C, 둘째 24→39°C, 셋째 31°C는 이야기 속 대비를 위한 예시다. 48초 이후 실내 온도 상승은 시간 압축으로 표현한 것이다. 57초의 31°C는 정전 뒤 **당분간** 덜 더운 방을 뜻한다. 그늘만으로 폭염이 해소된다고 설명하지 않는다.
- 센서의 48/34°C는 **바닥 표면**의 두 지점이다. 앞서 실내 공기 온도와 단위가 같아도 카드에 ‘바닥 온도’를 반드시 적는다.
- 도시 전력 사용률은 공급 가능한 용량에 대한 사용 비율로, 배터리 잔량이 아니다. 57→88→100% 뒤 ‘전력 과부하 · 정전’으로 전환한다. 정전 중 계기에 0%를 쓰지 않는다.
- 당일 정전은 48–81초까지 유지한다. 센서는 자체 배터리로 작동한다. 태양광은 장기적인 준비를 보여 주는 배경 설비이며, 정전 중 일반 태양광 패널만으로 전기가 복구되는 연출을 하지 않는다. 81초 시간 경과 후 도시 창의 은은한 불빛은 복구된 상태여도 된다.
- 표지에 **`기온·시간은 이야기 속 예시입니다.`**를 작은 안내로 한 번만 표시한다. 본편 수치 카드마다 긴 주석을 반복하지 않는다.

### 인물의 위치·동선 잠금

인물의 기준점은 두 발 가운데, 기본 발 높이 y=700이다. 몸 전체는 세계 폭 112, 높이 180 안에 그린다. 다음 위치 사이를 보간하고, 표에 없는 동안은 직전 위치를 유지한다.

| 인물 | 고정점과 이동 |
|---|---|
| 첫째 | 처음 집터 앞 x=530 → 9.0–9.6 x=800으로 들어감 → 22.6–24.6 잠깐 화면 왼쪽의 재촉 포즈(몸 위치 유지, 말풍선만 셋째 근경의 왼쪽 슬롯) → 37.4–40.7 x=800→1840 → 52.4–56.0 x=1840→3130 → 66.0–67.0 x=3130→3140 → 끝까지 3140 |
| 둘째 | 처음 x=1770 → 15.2–16.2 x=2000으로 들어감 → 40.0–41.5 입구를 향해 손을 뻗어 첫째를 맞음(위치 유지) → 52.4–56.0 x=2000→3290 → 71.0–71.6 x=3290→3340 → 끝까지 3340 |

| 이웃 둘 | 처음 x=2790,2910. 21.2–23.2 벤치 양끝을 잡고 x=2710,2830으로 80단위씩 함께 이동. 24–25 왼쪽 골목 입구의 담장 뒤로 퇴장 → 25–59는 골목 안에 있어 화면에서 숨김 → 59–60.6 왼쪽 골목에서 x=2300→2700, x=2440→2840으로 재등장 → 76.4–79.4에 각각 2860,2990으로 이동 → 끝까지 유지 |

22.6–24.6의 첫째 재촉은 셋째를 소개하는 원근 구도에서 **화면 왼쪽 작은 인물 삽입 없이**, 거리 왼쪽을 향한 셋째의 시선과 ‘첫째’ 꼬리 방향으로 처리한다. 멀리 있는 첫째를 근경에 순간이동시키지 않는다. 말풍선 꼬리는 화면 왼쪽 경계로 이어져 오프스크린 발화임을 나타낸다. 첫째의 손목 포즈는 세계 안에 유지하되 근경에서 보이지 않아도 된다.

단면 창을 쓸 때 실제 인물을 그 안에서 보이게 하고, 동일 인물 얼굴을 별도 창 아이콘으로 복제하지 않는다. 문을 지나갈 때만 문틀이 앞을 가릴 수 있다. 모두 같은 y=700에서 걷되, 경로를 교차시키지 않는다. 장면 말미 이웃 둘–첫째–둘째–셋째의 x는 2860 / 2990 / 3140 / 3340 / 3540으로 서로 분리된다. 도구를 든 손까지 포함해 겹치면 인물 폭부터 줄이고 자막 띠로 피하지 않는다.

| 표지 제목 | 112, 줄 간격 1.08 | 800, ‘늑대가 된’ / ‘여름’ 두 줄 |

카드와 말풍선 텍스트는 HTML 고정 오버레이로 구현해도 된다. 그래픽·아이콘·장식은 인라인 SVG로 그린다. 화면 글자는 SVG에 고정해 작아지는 방식보다 **HTML 글자의 최소 크기를 유지하는 방식**을 우선한다. CSS `clamp()`로 카드 항목명/말풍선은 최소 14 CSS px, 카드 숫자는 최소 20px, 챕터 제목은 최소 18px로 한다. 큰 화면에서는 위 viewBox 크기에 맞춘다. 휴대폰에서는 두 계기 값을 좌우 한 줄 그룹으로 배치하고 장식용 큰 숫자 위계만 줄인다. 카드 전체가 y=230 아래로 내려오지 않도록 패딩부터 줄인다.

챕터 제목 카드: 종이 바탕, 청록색 3단위 테두리, 반경 12, 왼쪽 8단위 색 띠. 안쪽 여백 24. 숫자 카드: 같은 모양, 항목명은 왼쪽, 숫자는 오른쪽. 두 칸일 때만 중앙에 2단위 구분선. 그림자 대신 아래로 6단위 어두운 종이 면을 하나 둔다. 전체 폭을 항상 채울 필요는 없으며 텍스트에 맞게 줄인다. 등장 시 y=8→0, opacity 0→1을 0.18초 ease-out. 카드나 헤드라인이 장면 전체를 덮는 슬라이드가 되어서는 안 된다.

### 종이 질감과 도형

인라인 SVG `<pattern>` 한 개로 16×16 셀에 반지름 0.5/0.7인 점 두 개를 엇갈려 놓고 잉크색 불투명도 0.035~0.05를 사용한다. 고정된 질감이며 매 프레임 난수를 만들지 않는다. 세계와 카드 위, 글자 아래에만 얹는다. SVG turbulence 필터, 큰 블러, grain 동영상은 필요 없다. 전경 외곽선은 4단위, 작은 도구는 3단위, 둥근 모서리와 round join. 원경 건물은 윤곽선 없이 넓은 면 위주로 그린다.

SVG 밖의 실제 HTML 텍스트로 구현한다. 중앙 정렬, 최대 폭은 화면 폭의 93%, 배경 `#173B38` 96% 불투명도, 글자 `#FFF9EB`, 모서리 12단위. 숫자·챕터 번호를 자막 옆에 붙이지 않는다. 바닥에서 24 viewBox 단위 상당을 띄운다. 글자 주변 가로 24·세로 16단위의 여백을 기본으로 하고 작은 화면에서는 가로 8px·세로 4px를 사용한다.

CSS 컨테이너 단위 미지원 시 JS가 측정한 `--stage-width`를 사용한다.

## 5. 플레이어 사양

### 표지와 종료 화면

초기 로드에서는 재생하지 않고 00:00에 대기한다. 하나의 16:9 프레임 안에 종이 바탕과 거리 O의 완성 전 집터를 배경으로 둔다. 왼쪽에 제목 ‘늑대가 된’ / ‘여름’, 오른쪽에는 작은 삼형제와 희미한 늑대 윤곽. 본편 위에 불투명한 새 슬라이드를 반복 삽입하지 않고, 표지만 예외로 편집 표지를 사용한다.

표지의 정확한 문구와 순서:

1. `아기 돼지 삼형제, 그다음 이야기`
2. `늑대가 된` / `여름`
3. 버튼 **`이야기 재생`**
4. `1분 28초 · 소리 없이 감상`
5. `기온·시간은 이야기 속 예시입니다.`

제목과 그림은 16:9 안에 배치하고, 재생 버튼과 안내 두 줄은 **프레임 바로 아래 표지 전용 HTML 영역**에 세로로 쌓는다. 360px에서 버튼과 안내가 절대 겹치지 않게 한다. 표지 전용 영역은 재생 시작 시 숨기며, 같은 아래쪽 공간에는 항상 제어부가 있다. 표지 버튼 최소 높이 44px, 안내 최소 14px. 표지 SVG 제목도 휴대폰에서 각각 최소 25px 상당으로 읽히게 한다. ‘여름’ 뒤에 마침표를 임의로 추가하지 않는다.

88초에는 시간을 `01:28 / 01:28`로 고정하고 최종 거리·메시지를 유지한다. 자막 S20은 종료와 함께 비우고, 프레임 아래에 **`다시 보기`** 버튼을 표시한다. 버튼은 제목·거리·자막을 가리지 않는다. 버튼을 누르면 완성된 집/늑대/팬/정보 카드를 모두 t=0 상태로 돌리고 즉시 다시 재생한다. 표지를 다시 거치는 별도 클릭을 요구하지 않는다.

### 제어부·상태 계약

프레임 바깥 아래쪽에 실제 HTML 버튼과 `input[type=range]`를 둔다. 제어부를 SVG 안에 그려 클릭 좌표로 처리하지 않는다.

- 본편 버튼 문구: 재생 중 **`일시정지`**, 멈춤 상태 **`계속 보기`**. 종료 시 이 토글은 비활성화하고 ‘다시 보기’를 사용한다.
- 탐색 막대: 0…88, step=0.1, 접근 가능한 이름 **`재생 위치`**. 처음 재생 전에는 비활성. 한 번 시작한 뒤에는 종료 상태에서도 탐색할 수 있다. `aria-valuetext`는 `00:42, 전체 01:28` 형식.
- 시간 표시: `00:00 / 01:28` 형식, 소수점 없음. 숫자 폭이 바뀌어 제어부가 흔들리지 않는다.
- 드래그/키보드 탐색을 시작하면 현재 재생 여부를 저장하고 잠시 멈춘다. 값이 바뀔 때마다 해당 시각을 즉시 그린다. 탐색 종료 시 원래 재생 중이었다면 이어 재생하고 원래 멈춤이었다면 멈춤을 유지한다. 88초로 이동하면 반드시 종료 상태. 종료에서 88초 미만으로 이동하면 종료 버튼을 숨기고 **멈춤 상태**로 해당 장면을 보여 주며 ‘계속 보기’를 활성화한다.
- 재생/재개 시 숨겨진 표지는 `hidden` 또는 `inert`로 키보드 순서에서 제외한다. 일시정지 때 화면을 새 표지로 덮지 않는다. 끝에 도달하면 다시 보기 버튼으로 포커스를 한 번 옮긴다.

### 벽시계 타임라인 — 필수 구현 방식

단일 `render(t)`가 카메라, 집 조립, 인물 위치·방향, 팬 각도, 색, 숫자, 카드, 말풍선, 자막, 종료 상태를 모두 결정한다. 모든 상태는 이전 프레임 없이 임의의 t에서 복원 가능해야 한다.

- 재생 시 기준 미디어 시간 `baseTime`과 `performance.now()`의 `baseNow`를 저장한다. 현재 시각은 `t = clamp(baseTime + (now - baseNow)/1000, 0, 88)`로 계산한다.
- 일시정지 시 이 식으로 최신 t를 먼저 확정하고 그 값을 저장한다. 재개·탐색 후에는 기준 시간을 새로 잡는다. `Date.now()`의 시스템 시계 변경에 의존하지 않는다.
- `requestAnimationFrame`은 그리기 요청일 뿐 시간의 원천이 아니다. **프레임 수나 `t += min(dt,0.1)` 누적으로 시간을 만들지 않는다.** 저사양 기기에서 프레임을 건너뛰어도 88초짜리 이야기가 늘어나지 않아야 한다.
- 팬 회전도 `angle += speed*dt`로 누적하지 않는다. 정해진 각속도 구간의 적분값을 t로 계산한다. 정전의 감속 종료 각도를 보존하여 48.6초 이후 각도가 튀지 않게 한다. 인물 방향 역시 그 시각의 이동 구간으로 결정한다.
- CSS/WAAPI를 쓰면 애니메이션을 독립적으로 흘려보내지 말고 `currentTime=t×1000` 등으로 같은 시간에 묶는다. 장면 진입 때만 실행되는 클래스 애니메이션·setTimeout 연쇄는 탐색 복원을 깨므로 사용하지 않는다.
- 종료·재시작·탐색 때 기존 rAF를 정리하고 루프는 최대 하나. DOM 요소와 SVG 경로는 초기화 때 만들고 render에서 반복 생성하지 않는다. 무작위 표현이 필요하면 고정 seed를 쓰지만 이 설계에는 난수가 필요 없다.

### 키보드·접근성·탭 전환

- `Tab`: 화면에 보이는 버튼→탐색 막대의 자연스러운 순서. 모든 버튼은 Enter/Space로 기본 활성화된다.
- 본문/프레임에 포커스가 있을 때 Space는 시작/일시정지/재개, 종료 상태에서는 다시 보기. Space의 페이지 스크롤을 막되, 버튼이나 입력 요소에 포커스가 있으면 글로벌 Space 처리와 이중 실행하지 않는다.
- 탐색 막대 포커스에서 좌우 화살표는 1초, Home=0, End=88. 키보드 탐색 중 반복 입력은 한 번의 탐색 세션으로 처리하고 keyup/blur 시 위 상태 계약을 적용한다. 다른 입력 요소에서 방향키를 가로채지 않는다.
- `visibilitychange`에서 문서가 숨겨지는 즉시 현재 t를 확정하고 일시정지한다. 탭으로 돌아와도 자동 재개하지 않는다. 화면 아래 상태 문구 `탭을 떠나 일시정지했어요.`를 표시하고 사용자가 재개하면 지운다. 이 문구는 영화 안의 라벨 제한과 별개인 제어부 안내다.
- SVG에 작품 제목과 짧은 설명을 제공한다. 자막 하나만 `aria-live="polite"`, `aria-atomic="true"`로 사용한다. 같은 문장을 프레임마다 다시 쓰지 않고 자막 ID가 바뀔 때만 업데이트한다. 자막 공백 구간에는 비운다. 탐색 중에는 변경마다 알리지 않고 탐색 종료 후 해당 자막을 한 번 알린다. 자동 갱신 게이지와 시간 표시는 live 영역으로 만들지 않는다.
- 키보드 초점 테두리는 황토색 3px, offset 3px. 텍스트 대비 최소 4.5:1. 숫자는 색뿐 아니라 값·항목명으로도 구분한다. 그림만 있는 제어 버튼은 쓰지 않는다.

### 움직임 줄이기

`prefers-reduced-motion: reduce`를 초기와 설정 변경 시 모두 반영한다. 재생 길이 88초, 자막 시간, 정보와 조작은 동일하다.

- 카메라의 연속 팬·줌은 없애고 아래 대표 구도로 즉시 전환한다: O(0), A(4), B(10), C(17), O(25), A(31), B(40.8), C(55.8), D(59), O(81). 이동 경로 도중 37.4–40.8과 52.4–55.8에는 출발 구도를 유지하고 도착 시점에 새 구도로 바꾼다.
- 패널의 낙하·튕김, 팬 회전, 달리기의 반동, 숨결의 흐름, 먼지, 지속 열 아지랑이는 제거한다. 집은 각 부재의 완성 시각에 나타나고 인물은 출발/도착 위치로 바뀐다. 문은 열기 완료 시각에 열린 모양이 된다.
- 인과는 열띠의 정적인 도착 모양, 정지한 팬, 바뀐 숫자, 그늘 경계로 남긴다. 늑대는 등장/후퇴 완료 시각에 정적인 상태로 바뀐다. 장면 사이 전체 페이드로 다시 슬라이드쇼를 만드는 대신 **같은 거리의 상태를 유지**한다.
- 정보 카드·자막 전환에는 최대 0.1초의 불투명도 변화만 허용한다. 점멸·섬광은 일반 모드에서도 사용하지 않는다.

### 반응형·세로 공간

- **그림 프레임 자체는 항상 16:9**, SVG는 `preserveAspectRatio="xMidYMid meet"`. 화면이 남으면 짙은 청록 레터박스. `cover` 크롭을 쓰지 않는다. 프레임 최대 폭 1600px.
- 바깥 래퍼 기본 `min-height:100vh`, 지원 시 `min-height:100svh`로 보완한다. `dvh`는 추가 보정으로만 사용하고 `dvh`만 있는 크기 계산은 금지한다.
- 넓은/가로 화면은 제어부에 104px을 예약하여 프레임 폭을 `min(1600px, 100vw - 24px, (100vh - 104px)×16/9)`에 해당하게 제한한다. 지원 시 같은 식의 vh를 svh로 덮어쓸 수 있다. 표지 안내가 추가되면 그 높이도 실제 측정해 예약한다.
- **세로 휴대폰은 높이 기준 축소보다 가로 폭 확보를 우선**한다. 폭≥360px에서 프레임은 `100vw - 16px`, 제어부는 2행: 첫 행 토글+시간, 둘째 행 전체 폭 탐색 막대. 버튼 높이와 탐색 입력의 터치 영역은 각각 최소 44px. 가로 스크롤 없음.
- 짧은 가로 창에서 최소 글자 크기/터치 영역과 화면 높이를 동시에 만족할 수 없으면 세로 스크롤을 허용한다. `body {overflow:hidden}`으로 제어부를 잘라 버리지 않는다. 16:9 프레임과 자막 최소 크기를 깨지 않는다.
- `ResizeObserver` 또는 resize 이벤트로 프레임 실제 폭을 갱신한다. 창 크기/방향 변경은 t와 재생 여부를 바꾸지 않는다. 360px에서 자막 16px, 안내 14px, 버튼 글자 16px 이상을 유지한다. 표지 버튼과 안내는 절대 위치로 한 줄에 억지로 넣지 않는다.

## 6. 구현자 체크리스트와 인수 기준

### 참고 작품에서 반복하지 않을 함정

- [ ] 장면별 배경 페이드와 둥실거림만으로 시간을 채우지 않는다. 조립, 열의 전달, 팬 가속·정지, 두 번의 이동, 문 열기, 천 펼치기, 측정, 안내가 실제 화면 사건이어야 한다.
- [ ] 첫째→둘째와 둘째→셋째 피신을 자막으로 생략하지 않는다. 출발 문, 달리는 몸, 도착 문이 같은 거리에서 이어진다.
- [ ] 셋째 소개에 단열·정원·태양광·나무·말풍선·체크리스트를 한꺼번에 붙이지 않는다. 카드 슬롯을 지키고 소품은 동작 순서로 보여 준다.
- [ ] 62–81초 **19초**를 문 열기와 세 형제의 당일 기여에 사용한다. 57–88초 **31초**의 피난 이후 구간을 앞 장면 때문에 줄이지 않는다. 마지막 메시지의 정지 시간을 작업 몽타주로 대체하지 않는다.
- [ ] 결말에 첫째·둘째를 구경꾼으로 두지 않는다. 첫째가 만든 그늘 아래로 이웃이 들어오고, 둘째가 고른 의자 위치에 쉰다는 결과까지 연결한다.
- [ ] 해결 장면에서 삼형제를 같은 좌표에 쌓지 않는다. 옷·안경·모자·손의 도구가 각각 보이고 자막 안전영역을 지킨다.
- [ ] 태양광 장착 즉시 정전 해결, 그늘막 설치 즉시 바깥 기온 하락, 전력 사용률을 잔량처럼 감소시키는 잘못된 인과를 만들지 않는다.
- [ ] 낮의 정전을 깜빡이는 밤 장면으로 만들지 않는다. 끊긴 전력과 멈춘 팬으로 사건을 읽게 한다.
- [ ] 소형 화면에서 SVG 자막을 비례 축소하지 않는다. 360px 실측, 최대 두 줄, 16px 하한을 확인한다. 상단 카드·말풍선도 읽을 수 있어야 한다.
- [ ] 누적 dt, 독립 CSS 루프, 되감기 뒤 남는 팬 각도·완성된 집·늑대·말풍선을 남기지 않는다.

### 최종 `index.html` 제작 후 실행 검수

1. **파일 계약:** 최종 제출 디렉터리에는 `index.html` 하나만 만든다. CSS/JS와 모든 SVG 도형·패턴·아이콘은 그 안에 포함한다. 외부 이미지·라이브러리·글꼴·오디오·네트워크 요청 없음. 참고 파일과 이 브리프를 고치지 않는다.
2. **파일 맨 위 주석:** doctype 앞 HTML 주석에 `현대적 주제: 폭염 시대의 주거와 공동체`, 장면 시작 `0/4/10/17/25/31/37/42/48/52/57/62/66/71/76/81/84초`, `전체 88초`, 메시지 `좋은 집은 함께 살아남는 곳이다.`를 적는다.
3. **연속 재생:** 파일 직접 열기→표지 재생 버튼→88초 종료→다시 보기까지 진행한다. 콘솔 오류·미처리 Promise 오류가 0건이며 끝의 버튼이 실제로 작동한다. 인터넷을 끈 상태에서도 동일하게 동작한다.
4. **시간:** visible 상태에서 재생 구간의 실제 경과가 88초, 종료 처리는 그 뒤 첫 rAF 이내다. 4~6배 CPU 제한에서 장면이 덜 부드러워져도 타임라인이 느려지지 않는다. 강제 프레임 정지 후에는 다음 프레임이 현재 t로 따라잡는다. 일시정지 10초는 영화 시간에 포함하지 않는다.
5. **일시정지:** 6.8초 조립, 45.5초 팬, 54초 달리기, 68.5초 천 펼치기에서 각각 멈춘다. 3초를 기다려도 카메라·부품·인물·팬·숫자·자막이 그대로여야 한다. 재개 후 중복 루프 없이 이어진다.
6. **탐색 복원:** 68→14→49→34→79→0→87초 순서로 왕복하고 각각 처음부터 같은 시각까지 재생한 화면과 비교한다. 집의 조립 단계, 인물 위치/방향, 팬 각도/정지, 문, 색, 수치, 말풍선, 자막이 일치한다. 48.0·48.6·57·62·81·84·88 경계값도 확인한다.
7. **종료 탐색:** 88초 탐색 시 종료. 88→45초 되감기 시 멈춤 상태, 다시 보기 버튼은 숨김, 계속 보기 활성. 다시 보기 연속 3회로 이전 종료/카드/인물이 남지 않는지 확인한다.
8. **탭 숨김:** 45초에 다른 탭으로 5초 이동한 뒤 돌아온다. 45초 부근에서 멈춰 있어야 하며 자동 재개되지 않는다. 재개를 눌러 남은 분량만 진행한다.
9. **입력·접근성:** 마우스 없이 Tab/Enter/Space/화살표/Home/End로 시작·멈춤·탐색·재시작. 버튼 Space 이중 실행 없음. 자막 live 알림이 숫자처럼 매 프레임 쏟아지지 않고 S번호 전환/탐색 종료에서만 바뀐다. 숨긴 표지 버튼으로 포커스가 들어가지 않는다.
10. **크기:** 1600×900 콘텐츠, 브라우저 1366×768·768×1024·**360×640**·390×844·640×360에서 확인한다. 16:9 프레임 보존, 자막 최소 16px·최대 두 줄, 재생/안내/제어부 잘림과 가로 스크롤 없음. 특히 20/35/49/61/68/74/79/86초에서 안전영역·말풍선·상단 카드를 확인한다. 360px에서 들어가지 않으면 장식·카드 패딩·설명 길이부터 조정하고 지정 자막은 유지한다.
11. **움직임 줄이기:** OS 설정을 재생 전/중간에 바꿔도 오류 없이 88초 동안 같은 사건·수치·자막을 볼 수 있다. 불필요한 팬/줌·회전·반동·흔들림·점멸은 없어야 한다. 설정 변경이 재생을 초기화하지 않는다.
12. **이야기 재검수:** 소리 없이 한 번 끝까지 보며 두 형의 피신, 셋째의 시선, 문을 여는 선택, 세 가지 작업, 이웃의 입장, 다음 여름의 세 집을 확인한다. 어느 장면도 자막만으로 사건을 대신하지 않아야 한다. 실제 구현·브라우저 검수 전에는 ‘모든 항목 통과’라고 보고하지 않는다.

구현 우선순위는 **연속된 공간과 인과 → 인물 동선 → 한글 가독성 → 시간/조작의 신뢰성 → 장식**이다. 시간이나 공간이 부족하면 구름·꽃·장식 점을 삭제하고, 위 장면·문장·두 단계 피신·각자의 기여는 보존한다.
